O ORFANATO DAS COISAS PERDIDAS — versão portátil para Windows
================================================================

COMO JOGAR
  1. Extraia TODO o conteúdo do ZIP para uma pasta (não execute de dentro do ZIP).
  2. Dê dois cliques em Orfanato.exe.
  Não é preciso instalar nada (sem Godot, Python, Node.js ou SDK).

REQUISITOS MÍNIMOS
  Windows 10 ou 11, 64 bits. Placa de vídeo com OpenGL 3.3 (modo de compatibilidade).
  ~200 MB livres. Teclado (mouse opcional). Fones de ouvido recomendados.

CONTROLES
  WASD / Setas ... mover          Shift ... correr (faz mais barulho)
  E ............... interagir / confirmar
  F ............... lanterna      Tab ... inventário      J ... diário
  Esc ............. pausa / voltar

ONDE FICAM OS SAVES E AS CONFIGURAÇÕES
  No diretório de dados do usuário, não na pasta do jogo:
  %APPDATA%\Godot\app_userdata\O Orfanato das Coisas Perdidas\
  Para "desinstalar", basta apagar a pasta do jogo (e, se quiser, a pasta acima).

AVISO
  Jogo de terror com temas de experimentos em crianças, body horror e perseguições.
  Há opções de acessibilidade em Configurações: legendas, redução de flashes,
  de tremor de tela e de distorção.

DICAS
  - Elias não luta. Observe, ouça e esconda-se.
  - A Cuidadora só abre um esconderijo se te VIR entrar nele.
  - O Morador sempre avisa antes de surgir: vibração, sons e a abertura pulsando.
